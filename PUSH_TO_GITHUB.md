# Push to GitHub

From a terminal in this directory:

```bash
git init -b main
git add index.html README.md .gitignore assets/preview.png
git commit -m "Launch Hamiltonian Melody"
git remote add origin https://github.com/JavaFXpert/hamiltonian-melody.git
git push -u origin main
```

If Git asks you to authenticate, sign in through your credential manager or use a GitHub personal access token with repository contents permission.
